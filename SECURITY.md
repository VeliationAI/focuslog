# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |

## Reporting a vulnerability

Please **do not** open a public issue for security-sensitive reports.

Email or DM the maintainers via [Veliation AI on GitHub](https://github.com/VeliationAI), or open a **private** security advisory on the repository if available.

Include:

- Description of the issue
- Steps to reproduce
- Impact assessment (if known)
- Any suggested fix

We’ll acknowledge receipt as soon as we can and coordinate a fix + disclosure.

## Scope notes

Focus Log is local-first. Hosted demos share an ephemeral SQLite database — treat public instances as **non-private** sandboxes, not personal vaults.
